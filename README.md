# Freelancer-Database-Management-System
Freelancer Database Management System is a MySQL project that models a freelancing platform. It manages users, projects, bids, payments, and reviews. The system uses relational concepts like keys, joins, and queries to ensure data integrity and extract insights such as top freelancers and lowest bids.
# Freelancer Database System

## Description
This project is a MySQL-based freelancer platform database.

## Features
- Users (clients & freelancers)
- Project posting
- Bidding system
- Payments tracking
- Reviews and ratings

## Tables
- Users
- Projects
- Bids
- Payments
- Reviews

## How to Run
1. Open MySQL
2. Run the SQL file:
   SOURCE freelancer_db.sql;
